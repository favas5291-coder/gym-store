# GymDrobe storefront design

| Token | Specification |
| --- | --- |
| Signature and primary action | Forest green `#0F3D3A` with white labels |
| Canvas and surface | `#F7F8F6` and `#FFFFFF` |
| Text and dividers | `#171C1B` and `#E9ECE8` |
| Secondary highlight | `#A9BDB3` with dark text |
| Typography | Plus Jakarta Sans for headings, Manrope for navigation, forms, names and prices |
| Section inset | Responsive 16–64 px |
| Corners | 8 px on primary actions, 10 px on cards and panels |

| Component | Behaviour |
| --- | --- |
| Navigation | White search header beneath green utility links. Active mobile tab has a tinted background and persistent label. |
| Campaign and categories | Static campaign photo and a horizontal product-photo rail on phones. Category links remain usable while the catalogue loads. |
| Product card | Catalogue price and variants, a labelled wishlist action, and consistent image framing. Ratings appear where supplied. |
| Purchase action | Forest green with white text. Existing variant and inventory gates control disabled states. Keyboard focus has a visible offset outline. |
| Forms | White surfaces and labelled fields. Existing loading states, validation feedback and retained field values continue through checkout. |
| Media and app | Catalogue-linked video loads on request. A product photo and link are shown when no video is available. Get App opens the existing install flow. |
