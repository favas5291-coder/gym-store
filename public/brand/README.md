# GymDrobe official logo sources

The SVGs trace the approved screenshot's white lettering and orange stroke. The dark square background is recreated; these are **reconstructions**, not the original master design files.

- `gymdrobe-lockup.svg`: transparent white wordmark with orange stroke; use on black/dark backgrounds.
- `gymdrobe-app-icon.svg`: full square artwork; platform clipping should supply launcher corner radius.

Before production, export platform-specific PNG/ICO sizes from the SVG with pixel verification. Do not treat an SVG as a valid iOS native app icon. Small favicons cannot retain full-name legibility.
