# GymDrobe branding usage

## Internal shop interface
The established in-store branding is the previous uppercase GYMDROBE text wordmark, used in the header and footer. Do not replace it with the external square icon or orange underline. Preserve page styling, checkout, accounts and all other existing functionality.

## External app identity
`gymdrobe-app-icon.svg` is the approved black/white/orange **external** square mark, reconstructed from the provided mockup (not an original editable brand master). Use this identity for app launchers, favicons, PWA installation, profile images and homepage/brand social sharing.
`gymdrobe-lockup.svg` is an external asset, not for injection into in-app headers, product pages or footer.

The long wordmark may become unreadable at small favicon sizes. Validate sizes and platform masks before release. Android and iOS use raster assets; a source SVG by itself is not sufficient.
